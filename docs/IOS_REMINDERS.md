# 工作台：锁屏提醒与待办同步

适用版本：1.5.0（build 11），Expo SDK 55，iOS 最低 16.1。

## 设置待办提醒

1. 新增或编辑待办，选择日期。
2. 需要精确到时分时，开启“指定时间”并调整时间。
3. 保存时允许工作台发送通知。
4. 在“计划 → 锁屏提醒”查看权限和已预定数量；点击“10 秒测试”，锁屏等待测试通知。

预定的是 iOS 本地通知，不依赖 EAS、推送服务器、APNs 证书或联网。预定完成后，App 不在前台时由系统负责通知。

- 仅日期：当天本地时间 09:00 提醒；桌面小组件当天零点起显示。
- 指定时分：指定时间提醒，桌面小组件也到该时间才显示。
- 未设置日期：不发送到期提醒，小组件可直接显示。
- 已完成、已取消日期、已过提醒时间：不新建提醒。
- 编辑或改期更新原提醒，完成取消原提醒，不重复排程。
- 优先预定最近的 32 条未来待办，超出的数量会在计划页提示。再次打开或刷新 App 会重新补排。
- 点击待办通知进入对应待办编辑页。

## 手机设置

在“设置 → 通知 → 工作台”开启“允许通知”、锁定屏幕、通知中心、横幅和声音。预览选择由用户决定；不希望别人看到内容时，可选择“解锁时”。

锁屏通知卡片的外观由 iOS 绘制，不是自定义小组件。通知预览、静音、专注模式、通知摘要以及亮屏行为由系统控制，App 不能保证强制亮屏或绕过静音/专注模式。测试通过仅说明当时的手机设置允许该通知。

官方说明：[Apple 本地通知](https://developer.apple.com/documentation/usernotifications/scheduling-a-notification-locally-from-your-app)、[Apple 通知设置](https://support.apple.com/en-us/108781)、[Expo SDK 55 通知接口](https://docs.expo.dev/versions/v55.0.0/sdk/notifications/)。

## 重复待办

支持每天、每周和每月；必须先设置日期。完成当前待办后生成下一期，保留标题、备注、分组、星标和提醒时分，原待办保留在已完成历史中。

过期多期时只创建下一条未来待办，不补大量历史。每月 31 日在短月份使用该月最后一天，后续月份恢复原来的 31 日。撤销完成不会删除已经生成的下一期；再次完成也不会重复生成。

重复规则是本机数据，当前网页待办 API 没有对应字段，不承诺跨设备同步重复规则。尚未完成当前待办时，不会自动生成后续待办或周期通知。

## 同步与小组件反馈

先读取本机 SQLite 并显示待办，再后台连接网页；没有网络也可查看、添加和编辑。网络失败保留本机改动，回到 App 或手动刷新时重试。同步过程中产生的新改动会继续补跑，不将旧云端结果覆盖到新本机编辑上。

计划页显示小组件快照的写入时间和错误。写入成功不等于桌面已重绘；WidgetKit 的实际显示仍由 iOS 调度。App 内保留未来待办，桌面小组件只显示已到时间的待办。

云端创建仍有一个异常网络边界：服务器已创建但响应丢失，同时用户又改了标题或日期，后续同步可能无法认领旧内容而产生重复云端待办。当前客户端未使用服务端幂等键，因此不能承诺所有断网情形都绝无重复；本次修复覆盖正常连续编辑与在途同步的补跑，不代表已经改造网页服务端幂等协议。
